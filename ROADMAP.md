# Roadmap

## MVP target

The first public release should deliver an end-to-end learning experience:

- Public website
- Authentication
- User profile
- Project Management Academy
- Scrum Master Academy
- AI Tutor MVP
- Search
- Progress tracking
- Basic quizzes
- PWA-ready responsive web experience

## Implementation waves

| Wave | Focus | Key repositories |
|---|---|---|
| Wave 0 | Foundation | platform-foundation, engineering-standards, infra, shared-ui |
| Wave 1 | Platform Core | auth, api-gateway, data-platform, cms |
| Wave 2 | Learning MVP | web, learning-service, assessment, ai-tutor |
| Wave 3 | Credentials | certification, analytics, notifications |
| Wave 4 | Expansion | mobile, marketplace, community, labs |

## Sprint starter plan

| Sprint | Objective |
|---|---|
| Sprint 0 | GitHub setup, standards, CI/CD skeleton, infra planning |
| Sprint 1 | Infrastructure baseline and shared UI setup |
| Sprint 2 | Authentication service scaffold |
| Sprint 3 | API gateway and CMS scaffold |
| Sprint 4 | Web platform foundation |
| Sprint 5 | Project Management Academy content MVP |
| Sprint 6 | Scrum Master Academy content MVP |
| Sprint 7 | AI Tutor MVP |
| Sprint 8 | Search and progress tracking |

## Release gates

| Gate | Criteria |
|---|---|
| Alpha | Auth + web + CMS skeleton deployed |
| Beta | Learning path + AI Tutor MVP + progress tracking |
| MVP | Project Management and Scrum Master Academy usable end-to-end |
| Production | Security, performance, monitoring, backup, DR, and compliance checks passed |
