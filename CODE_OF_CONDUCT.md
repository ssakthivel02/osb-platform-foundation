# Code of Conduct

## Expected behaviour

- Be respectful.
- Be precise.
- Challenge ideas, not people.
- Prioritize learner safety, accessibility, and trust.
- Document important decisions.

## Unacceptable behaviour

- Harassment or discrimination.
- Unsafe handling of user data.
- Bypassing review or security controls.
- Misrepresenting AI-generated content as verified without review.

## Enforcement

Project maintainers may remove content, block contributions, or escalate issues based on severity.
