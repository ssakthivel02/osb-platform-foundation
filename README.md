# OmSaravanaBhava Learning Ecosystem — Platform Foundation

**Status:** Architecture v1.0 Approved  
**Repository:** `osb-platform-foundation`  
**Purpose:** Master documentation, governance, roadmap, and architectural baseline for the OmSaravanaBhava Learning Ecosystem.

## Mission

Build a global AI-native learning ecosystem that combines professional education, enterprise simulations, AI tutoring, certification, community, and cultural learning into a single scalable platform.

## Repository role

This repository is the source of truth for:

- Vision and strategy
- Architecture baseline
- Engineering governance
- Product roadmap
- ADR process
- Repository standards
- Security and contribution policy

It does **not** contain application source code.
